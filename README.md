# ShiftFix MVP

This is a browser-based working prototype of ShiftFix.

## How to run
1. Open `index.html` in Chrome, Edge, Safari, or Firefox.
2. Add equipment.
3. Create trouble tickets.
4. Generate, copy, print, or save handoff reports.
5. Tickets and equipment are stored in your browser using localStorage.

## Included
- Dashboard
- Equipment list
- Trouble ticket creation
- Searchable ticket history
- Status tracking
- Automatic handoff report formatting
- Print / Save PDF support
- Mobile-friendly layout

## Important limitation
This version is local to one browser and one device. It does not yet include:
- User accounts
- Cloud database
- Multi-user teams
- File/photo uploads
- Real AI generation
- Billing

Those should be added after the workflow is tested.
